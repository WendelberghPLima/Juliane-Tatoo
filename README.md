# Juliane — Estética e Remoção de Tatuagem

Landing page profissional desenvolvida para apresentar os serviços da profissional Juliane, com foco em remoção de tatuagem, remoção de micropigmentação e Peeling de Hollywood.

O projeto foi desenvolvido com foco em um design moderno, elegante, responsivo e com uma experiência simples para os visitantes encontrarem informações sobre os procedimentos e entrarem em contato.

## ✨ Funcionalidades

- Página inicial com seção Hero
- Apresentação da profissional
- Seção de procedimentos
- Galeria de resultados
- Filtros de procedimentos
- Seção "Como funciona?"
- Agenda de próximos atendimentos
- Perguntas frequentes (FAQ)
- Seção de contato
- Página de Pós-Procedimento
- Design responsivo para dispositivos móveis

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Font Awesome
